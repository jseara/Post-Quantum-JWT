Post-quantum JWT transport lab

Issue and verify JWTs signed with classical and post-quantum algorithms, and see which layer breaks when they get big. Every button sends a real request from this browser.

The project's overview and setup steps are in its README.

Read-only: recorded results. This copy of the page has no test stack behind it, so the buttons replay what the committed runs recorded, and no request is sent. For live requests, run make serve in a clone of the repository and open http://localhost:8080/.

Signatures use ephemeral experiment keys held in the app's memory; tokens are not credentials. The jwt cookie is HttpOnly, so this page cannot read it, only ask the app to verify it. Bar limits are documented defaults: Chromium's 4,096-byte cookie (name + value) and nginx's 8,192-byte header line.
